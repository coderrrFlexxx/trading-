TradeVault — Trading Journal
=============================

A simple, offline-first trading journal.

Features:
- Track trades (Symbol, Side, Entry, Exit, Qty, Strategy)
- Dashboard with Net P&L, Win Rate, Total Trades, R:R
- Calendar view with monthly P&L
- Analytics: donut chart, P&L bars, strategy breakdown
- Playbook: save your trading strategies and rules
- Reviews: journal learnings after sessions
- Risk Calculator: position size from account risk %
- Backtesting: log historical strategy tests
- Export / Import JSON backups
- Light & Dark theme (Light off-white is default)
- Works offline (Service Worker + PWA)
- All data stored locally in browser (no server)

Tech:
- Plain HTML / CSS / JavaScript
- No frameworks, no build step
- localStorage persistence

Usage:
1. Open index.html in any modern browser
2. Or serve via any static host (GitHub Pages, Netlify, etc.)
